# Шрифт Meat Auto: замеры Manrope (27.10.2026)

Решение Влада: на сайте только Manrope, вариативный, свой файл (без Google Fonts по сети).
Замеры — fontTools 4.63 (`TTFont`, `getBestCmap`, `fvar`), не на глаз.

## Источник

- `source/fonts/Manrope[wght].ttf` — официальный репозиторий `google/fonts`, `ofl/manrope/Manrope[wght].ttf`,
  скачан 27.10.2026; версия **4.505**; 164 700 Б; SHA-256 `3ae11c49…9d6ae6`.
- Лицензия SIL OFL 1.1: `source/fonts/OFL-Manrope.txt` (совпадает байт в байт с `dist/assets/fonts/OFL-Manrope.txt`).

Поправка критика 2 предполагала, что U+2011 в вариативном Manrope нет, — его там нет только в
подмножестве latin главной v2; в полном файле и в нашем подмножестве он есть. `<span class="nw">из-за</span>`
по-прежнему удобнее (видно в разметке), но и `из‑за` с U+2011 отрисуется Manrope.

**Набор знаков сайта** (все `dist/*.html`, `dist/js/*.js` без 3D-бандла, `meatwash-content.json`,
`src/data/cars.json`, тела, части и главная v2) — 172 разных знака. Из них нет в шрифте только
**↗** (в старых частях `dialogs`, `locations`, `membership` — заменить иконкой `{{icon:arrow-up-right}}`,
WP5/WP6) и **─** U+2500 (в комментарии JS, на экран не выводится). В полном файле этих двух знаков тоже нет —
подмножество ничего не теряет. Числа в ценах пишет `toLocaleString('ru-RU')` с U+00A0 (есть в шрифте),
не U+202F (нет).

Возможности: `kern`, `liga`, `calt`, `tnum` (цифры одной ширины в ценах), `pnum`, `case`. Хинтинг снят
(`--no-hinting`), как у веб-шрифтов Google.

## Как пересобрать

```
pip install fonttools brotli     # один раз
npm run font                     # scripts/font.sh → dist/assets/fonts/manrope-vf.woff2
```

Диапазоны: `U+0020-007E, U+00A0-00FF, U+0400-045F, U+2010-2027, U+2030-203A, U+2116, U+20BD, U+2190-2193, U+2212`.
Сборка воспроизводима: повторный запуск даёт тот же файл байт в байт.

## Подключение (поправка критика 28)

`@font-face` объявлен не в CSS, а в `<head>` каждой страницы (`scripts/content.mjs`, константа `FONT`):

```html
<link rel="preload" href="assets/fonts/manrope-vf.woff2?v=8d909079" as="font" type="font/woff2" crossorigin>
<style>@font-face{font-family:'Manrope';src:url('assets/fonts/manrope-vf.woff2?v=8d909079') format('woff2');font-weight:200 800;font-style:normal;font-display:swap}</style>
```

`?v=` — первые 8 знаков SHA-256 файла: адрес в preload и в `@font-face` один и тот же, шрифт
скачивается один раз, а новый файл получает новый адрес (у хостинга долгий кэш статики).
Второй `@font-face` в CSS не добавлять. `server/404.html` (WP1) пишет тот же блок с адресом от корня.
В CSS — только `font-family: var(--sans)` (`tokens.css`).

Arsenal, `manrope.woff2`/`.ttf` и подмножества v2 страницы не подключают; из выкладки их убирает `prune-deploy` (WP7).
