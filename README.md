# MEATWASH — сайт Car Care Club

Публичный сайт: https://meatwash.ru/ (хостинг reg.ru, загрузка вручную); копия на GitHub Pages — https://paul1l.github.io/MeatWash-v3.0/.

Совместная разработка: [CONTRIBUTING.md](CONTRIBUTING.md) — ветки, проверки перед pull request, каталог услуг.

**Текущая версия (с 26 сентября 2026):** за основу взята версия https://meat-wash.vercel.app — первый экран на фотографиях (`dist/js/stage.js`, кадры `dist/assets/shots`), блок «До и после», «Гараж услуг». Поверх неё — наши исправления записи по филиалам, доступности, мета и деплоя. **Версия 3.0 (с 27 сентября 2026):** кнопка «Оживить Porsche» на первом экране по нажатию загружает интерактивную 3D-сцену (three.js, модель 930 Turbo) поверх фото; до нажатия 3D ничего не запрашивает, сайт работает как 2.0. В «Гараже услуг» — переключатель «Показать в 3D». **Версия 3.1 (с 28 сентября 2026):** первый экран — статичная фотография без закреплённой сцены и глав; «Оживить Porsche» и «Гараж услуг» объединены в один 3D-гараж, который открывается кнопкой «Открыть 3D-гараж» (на первом экране и в промоблоке). Устройство проекта и ловушки — в `CLAUDE.md`, устройство модуля — в `src/porsche3d/README.md`, замеры — в `QA.md`.

GitHub Actions публикует содержимое `dist` через `.github/workflows/pages.yml` при каждом push в `main`. В Settings → Pages источник публикации — GitHub Actions; корень репозитория не является папкой сайта.

## Домен meatwash.ru

Сайт meatwash.ru лежит на хостинге reg.ru, файлы туда загружаются вручную. GitHub Pages публикует копию на `paul1l.github.io/MeatWash-v3.0/` при каждом слиянии в `main`; на meatwash.ru изменения попадают только после ручной загрузки. `canonical` копии — meatwash.ru, поиск индексирует домен.

Что загружать: архив `github-pages` со страницы последнего запуска Actions → «Deploy Meatwash website» → Artifacts (внутри `artifact.tar` — `dist` с версиями `?v=` у CSS и JS и без лишних файлов; хранится сутки). Содержимое — в папку сайта на хостинге, с заменой файлов. Если залить `dist` из репозитория как есть — сайт работает, но после обновления посетители могут получать старые CSS и JS из кэша.

Автоматическая выкладка на хостинг по FTP/SFTP из `pages.yml` была сделана и снята по решению владельца — коммит `d0350f6`, отменён в `ebc8c19` (вернуть: `git revert ebc8c19`).

Яндекс Вебмастер: код подтверждения `58e9b738e3e02ac7` — в `site.analytics.webmaster`; `npm run build` ставит мета-тег `yandex-verification` на все страницы и создаёт файл `dist/yandex_58e9b738e3e02ac7.html` (способ «HTML-файл»), `npm run check` сверяет оба с JSON. Права подтвердятся, когда файл или страницы с мета-тегом окажутся на хостинге meatwash.ru. После — в Метрике у счётчика «Привязать к Вебмастеру».

Адрес сайта в коде — `https://meatwash.ru/`: `canonical`, `og:url`, `og:image`, JSON-LD, `sitemap.xml`, `robots.txt`, Политика и Согласие (`SITE` в `scripts/content.mjs` и `scripts/check.mjs`). Внутренние ссылки относительные — сайт работает и в корне домена, и в папке GitHub Pages. Счётчик Метрики принимает данные только с `meatwash.ru` (фильтр в настройках счётчика): на адресе GitHub визиты не считаются.

## Запуск

Нужен Node.js. Запустите `START.cmd` или `npm start`. По умолчанию сервер использует порт 4173, START.cmd — 4176. Для другого порта задайте переменную `PORT`. Установка зависимостей для просмотра не нужна: сайт — готовые файлы `dist`, 3D-движок уже собран в `dist/js/porsche3d.bundle.js`.

Открывать `dist/index.html` через `file://` нельзя: браузер блокирует ES modules. Используйте локальный сервер или любой статический HTTP-хостинг. Для публикации достаточно содержимого `dist`.

## Первый экран

Статичная фотография Porsche в клубном зале (`cf-hero-clean`), вордмарк MEATWASH, «Записаться» и «Услуги и цены»; справа внизу (на телефоне — под текстом) — вход в «Гараж услуг»: превью, название, подпись «Выберите услуги и рассмотрите автомобиль в 3D» и кнопка «Открыть 3D-гараж». Дальше — обычная прокрутка страницы, без закреплённой сцены и глав. На телефоне в портрете первый экран — колонкой: фото забирает остаток высоты (не меньше 190 px, не больше 62 %), ниже текст, вход в гараж и постоянная кнопка записи внизу экрана.

## «Гараж услуг» (3D)

Обе кнопки «Открыть 3D-гараж» (первый экран и промоблок) и тизер на `services.html` (`./#garage`) открывают одно окно `<dialog id="garage">`. Оболочка — название, закрытие, «Загружаем 3D-гараж» — появляется сразу; по нажатию проверяется WebGL 2, затем скачиваются бандл (~170 КБ gzip) и модель (1,2 МБ телефон / 2,2 МБ компьютер). Процент показывается только для модели (размер известен из манифеста сборки), на остальных этапах — индикатор без процента. После первого кадра появляются машина и панель услуг.

- Компьютер: большое модальное окно, слева машина (поворот мышью, приближение колесом и кнопками «+»/«−» в пределах, «Общий вид», подсказка), справа панель: четыре вкладки категорий, работы с ценами (состав программ и пакетов — по «Состав»), внизу «Выбрано: N» с итогом «от …» (работы без цены — «+ после оценки»), список выбранного раскрывается по нажатию; «Записаться на мойку» и/или «Заявка с фото».
- Телефон: полноэкранно — шапка с закрытием и «Свернуть услуги», машина (~42 % высоты), четыре вкладки категорий (в одну строку, на очень узкой панели — 2×2), список, «Выбрано: N» с итогом и запись внизу; «Свернуть услуги» отдаёт экран машине. В области модели палец крутит машину (два пальца — приближение), список листается свайпом, страница за окном неподвижна. В альбоме — две колонки. Учтены безопасные зоны и `dvh`.
- Работа → ракурс и эффект: камера плавно перелетает к детали (колесо, крыло, фара, порог, лобовое стекло, капот, перед); мойки смывают пыль с бортов, полировка — риски и свет по борту, у колеса, крыла, капота, оклейки, фар и салона по детали проходит мягкий блик, у «Антидождя передней полусферы» на лобовом стекле появляются капли, стягиваются в бусины и скатываются. Ручное управление во время эффектов работает; при «уменьшить движение» блика нет, капли стоят без движения. Салон модели упрощён, поэтому химчистка и кожа показываются общим видом борта, без пролёта камеры внутрь.
- Названия работ — как в каталоге, цены — из того же JSON. Программа мойки выбирается одна; работа, уже входящая в выбранный пакет (например, «Антидождь передней полусферы» в пакете «Экстерьер»), помечается «входит в пакет» и отдельно не начисляется. Выбор хранится до конца визита (sessionStorage), повторное открытие его не сбрасывает.
- «Записаться на мойку» закрывает гараж и открывает выбор филиала с составом в строке «Вы выбрали: …»; ссылка филиала несёт корзину мойки (`yclients.js`, формат `short?o=m-1s…` — недокументированный). Остальные работы — «Заявка с фото»; при смешанном выборе видны обе кнопки, и каждое окно напоминает о второй части.
- Закрытие — крестик, Esc, фон окна (на компьютере) — работает в любом состоянии: загрузка отменяется, сцена освобождает видеопамять, отрисовка останавливается, прокрутка и фокус возвращаются. Поздно закончившаяся загрузка окно не открывает; повторные нажатия не создают вторую сцену.
- Ошибка (сеть, тайм-аут, шейдеры, потеря контекста): «Не удалось открыть 3D-гараж. Вы можете повторить попытку или выбрать услуги в каталоге.» — «Повторить», «Открыть услуги», «Закрыть». Без WebGL 2 — своё сообщение без повтора. Фотография 3D-гаражом не притворяется.

## Доступность

Диалоги — native `<dialog>`: фокус внутри окна, Escape, возврат фокуса на кнопку, открывшую окно. Вкладки гаража — ARIA tablist (стрелки, Home, End); область 3D управляется с клавиатуры (стрелки — поворот, «+»/«−» — приближение, Home — общий вид). При `prefers-reduced-motion` и `?motion=reduce` камера переходит к ракурсам без анимации, без инерции и проезда вдоль борта. На телефоне в портрете есть постоянная кнопка записи.

## Статьи

Пункт «Статьи» в шапке, меню и подвале ведёт на `articles.html`. Статья — `src/content/articles/<slug>.html`, её заголовок, описание, дата и фото — в `src/content/pages.mjs` (`ARTICLES`). Цены пишутся только подстановкой `{{price:<название работы из каталога>}}` (и `{{program-from:i}}`, `{{program-includes:i}}`) — они берутся из `meatwash-content.json`, а `npm run check` находит любую цену не из каталога. После правки — `npm run build`. Первая статья: «Автомобиль к зиме: что сделать до первых реагентов».

## Яндекс Метрика, Вебмастер, cookie и персональные данные

- Номер счётчика Метрики и код подтверждения Вебмастера — в `site.analytics` (`meatwash-content.json`), затем `npm run build`: мета-теги появятся в `<head>` всех страниц, а для Вебмастера ещё файл `yandex_<код>.html` в корне. Счётчик — 113253931, код Вебмастера — 58e9b738e3e02ac7.
- Метрика загружается только после «Принять» в уведомлении о cookie; «Отказаться» — сайт работает полностью, без статистики. «Настройки cookie» в подвале меняют решение. Параметры счётчика — как в его коде из интерфейса Метрики (Вебвизор, карта кликов, внешние ссылки, точный показатель отказов), но без noscript-пикселя: он считал бы и без согласия. Вебвизор назван в уведомлении, Политике и Согласии; выключая его (`webvisor: false` в `js/analytics.js`), уберите и упоминания — `npm run check` сверяет.
- Цели для Метрики (Цели → JavaScript-событие): `booking_open`, `booking_branch`, `phone_click`, `map_open` (параметр `source`: `footer` — «На карте» в подвале, `touch` — карту включили касанием, `map` — переход в карту на компьютере), `garage_open`, `garage_ready`, `garage_book`, `garage_request`, `request_open`, `request_sent`, `club_card` (переход к оформлению клубной карты).
- Политика (`privacy.html`) и отдельное Согласие (`consent.html`) составлены по 152-ФЗ и описывают то, что сайт делает на самом деле: форм нет, запись — в YCLIENTS, Метрика с Вебвизором — только с согласия, Яндекс Карты — когда посетитель прокрутил к блоку «Локации». Реквизиты оператора — `site.operator`; пока не заполнены, в документах жёлтые пометки, а `npm run check` предупреждает. Документы — шаблон, а не юридическая консультация: перед публикацией их стоит показать юристу; уведомление Роскомнадзора об обработке ПДн подаёт оператор.

Единый файл данных — `dist/assets/meatwash-content.json`. После изменения программ, услуг или филиалов выполните `npm run build`, затем `npm run check` и сохраните обновлённые страницы и `dist/js/data.js`. На странице услуг видна одна категория: переключатели — вкладки (без скриптов все четыре идут подряд), прежние якоря (`#price-film`, `#program-2` и т. п.) открывают нужную категорию и встают к подразделу. Переключатель типа кузова обновляет пять цен; состав программ — по «Подробнее» (native details). Стили — `dist/css/catalog.css`. «Гараж услуг» берёт названия, цены и категории из того же JSON (через `js/data.js`): вкладки — те же четыре категории, программы и пакеты мойки взаимоисключающие, их цена — для выбранного кузова, работы из состава программы или пакета (`programItems`) второй раз не считаются, цены «после оценки» в сумму не входят — итог называет их отдельно.

Онлайн-запись у площадок разная: Мясницкая — компания 906067 в `n975571.yclients.com`, Технопарк — компания 1743348 в `n1982508.yclients.com`. Общий адрес открывал только Мясницкую, поэтому окно записи и карточки локаций ведут в запись своей площадки. Адреса лежат в `meatwash-content.json` рядом с данными локации; `npm run check` следит, что обе ссылки есть на странице.

Неподтверждённые «1000+ клиентов» удалены. Рейтинг 5.0 указан в исходном сайте; 28 сентября 2026 виджет Яндекс Карт показывал 5,0 у обеих студий. Блок клуба рассказывает о реальных сертификатах и корпоративном уходе, без выдуманного платного членства. Мойка записывается в YCLIENTS (окно выбора филиала; ссылка филиала несёт корзину мойки — PR #5, `js/yclients.js`, `assets/yclients.json`). Остальные работы — «Заявка с фото» (`js/request.js`): имя, контакт, автомобиль, студия, комментарий, до 6 фото и обязательное согласие (`consent-request.html`). Отправка — только на адрес `site.requests.endpoint` (POST multipart/form-data, ответ JSON `{"ok": true}`); пока его нет, форма не отправляет и даёт телефоны студий. Никакие заявки не имитируются. Канал приёма (почта на хостинге reg.ru, CRM, бот — на стороне сервера) выбирает владелец; от выбора зависят тексты Политики и Согласия (например, передача данных зарубежному сервису).

## Яндекс Карты

В карточках «Локации» (главная и «О нас») вместо фото студии — карта этой студии: виджет карточки организации Яндекс Карт (`map-widget/v1/org/<slug>/<id>/?ll=<lon,lat>&z=16`, формат кода «Поделиться → Встроить»), по одному на студию. Виджет создаётся, когда карточка подходит к экрану (в разметке iframe нет); область заранее нужного размера, поэтому страница не прыгает. На телефоне поверх карты лежит прозрачный слой: свайп листает страницу, касание включает карту. Если Яндекс Карты недоступны — внутри области сообщение, «Повторить» и «Открыть в Яндекс Картах»; адрес, телефон и запись работают без карты. «На карте» в подвале ведёт к карте нужной студии. Org id и координаты — в `meatwash-content.json` (координаты взяты из данных самого виджета).

## Проверка исходников

`npm run check` проверяет исходники и ресурсы, `npm run catalog` пересобирает каталог. Ручная проверка — в браузере: desktop/mobile, меню, цены, диалоги записи, «Гараж услуг» во всех состояниях (загрузка, готов, ошибка, нет WebGL), `?motion=reduce`, ошибки консоли и переполнение. См. `QA.md`.

Запросы к imagegen (улучшенный кадр клуба, первый кадр прошлой версии) — в `IMAGE-PROMPT.md`.
