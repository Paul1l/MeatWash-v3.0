# MEATWASH — сайт Car Care Club

Публичный сайт: https://paul1l.github.io/MeatWash-v3.0/

Совместная разработка: [CONTRIBUTING.md](CONTRIBUTING.md) — ветки, проверки перед pull request, каталог услуг.

**Текущая версия (с 26 сентября 2026):** за основу взята версия https://meat-wash.vercel.app — первый экран на фотографиях (`dist/js/stage.js`, кадры `dist/assets/shots`), блок «До и после», «Гараж услуг». Поверх неё — наши исправления записи по филиалам, доступности, мета и деплоя. **Версия 3.0 (с 27 сентября 2026):** кнопка «Оживить Porsche» на первом экране по нажатию загружает интерактивную 3D-сцену (three.js, модель 930 Turbo) поверх фото; до нажатия 3D ничего не запрашивает, сайт работает как 2.0. В «Гараже услуг» — переключатель «Показать в 3D». Устройство проекта и ловушки — в `CLAUDE.md`, устройство модуля — в `src/porsche3d/README.md`, замеры — в `QA.md`.

GitHub Actions публикует содержимое `dist` через `.github/workflows/pages.yml` при каждом push в `main`. В Settings → Pages источник публикации — GitHub Actions; корень репозитория не является папкой сайта.

## Запуск

Нужен Node.js. Запустите `START.cmd` или `npm start`. По умолчанию сервер использует порт 4173, START.cmd — 4176. Для другого порта задайте переменную `PORT`. Установка зависимостей для просмотра не нужна: GSAP и ScrollTrigger включены в `dist/vendor`.

Открывать `dist/index.html` через `file://` нельзя: браузер блокирует ES modules. Используйте локальный сервер или любой статический HTTP-хостинг. Для публикации достаточно содержимого `dist`.

## Сценарий

Секция `#scene` закреплена на время прокрутки, GSAP ScrollTrigger ведёт `progress` от 0 до 1. Длина трека — одна переменная `--scene-len` (780svh на компьютере, 400svh на телефоне и планшете в портрете, 540svh в низком альбоме); доли от неё не зависят. Точки: 0.00 — первый экран; 0.20 — кузов; 0.40 — салон; 0.60 — полировка; 0.80 — керамика; 1.00 — финал. Витрина показывает одну машину в шести состояниях (`LADDER` и границы `LADDER_AT` в `config.js`: кадр меняется между главами), кадры перекрёстно проявляются.

## 3D-режим «Оживить Porsche»

Кнопка стоит в нижней строке первого экрана (на телефоне — отдельной строкой над «Записаться»); скрипт кнопки грузится после загрузки страницы. Нажатие скачивает бандл (~173 КБ gzip) и модель (1,2 МБ телефон / 2,2 МБ компьютер) с процентом загрузки, отменой и повтором; после первого кадра сцена проявляется поверх фото — пыльная машина, как на фото, — и один раз показывает себя (~7 с, можно остановить). Ракурсы «Общий вид», «Кузов», «Диски», поворот мышью или горизонтальным жестом; колесо и вертикальный жест листают страницу. Дальше, как в версии 1.0, прокрутка ведёт камеру по главам: грязь смывается, салон (кожаный кокпит), полировка со светом по борту, капли на капоте, финал. «Обычный вид» (в главах — кнопка под «Гаражом услуг») возвращает фото-витрину на том же месте и освобождает видеопамять. Без WebGL 2 кнопки нет; при ошибке или потере контекста остаётся фото. «Отмена» во время скачивания самого бандла запрос не прерывает (браузер не умеет отменять `import()`) — сцена просто не запускается.

## Доступность и статичный режим

`prefers-reduced-motion: reduce`, `?motion=reduce`, Save-Data и ошибка загрузки кадра витрины (или 25 с без него) включают статичный режим: главы идут обычными блоками на кадрах из `assets/shots`, без длинного закреплённого скролла, «Гаража услуг» нет. 3D-режим в статичном режиме доступен, но без показа и параллакса. Диалоги используют native dialog, Escape и возврат фокуса; скрытые главы исключены из фокуса через `inert`. На телефоне в портрете есть постоянная кнопка записи.

## Фактические данные и запись

Данные сверены 23 сентября 2026 года с https://meat-wash.vercel.app: страницами `/programmy`, `/uslugi`, `/detailing`, `/adresa`, `/o-nas`. Полный каталог содержит 5 программ мойки, 20 цен для четырёх типов кузова и 39 работ в восьми категориях. Порошковая покраска дисков указана отдельно без выдуманной цены. Адреса, телефоны, часы работы, преимущества площадок, предложение для новых клиентов и способы оплаты перенесены из источника. Условия и окончательная стоимость уточняются перед работой.

Единый файл данных — `dist/assets/meatwash-content.json`. После изменения программ, услуг или филиалов выполните `npm run build`, затем `npm run check` и сохраните обновлённые страницы и `dist/js/data.js`. Каталог генерируется в HTML, поэтому не требует дополнительного запроса. Переключатель типа кузова обновляет пять цен; раскрывающиеся списки работают через native details. Стили — `dist/css/catalog.css`. Модальные окна четырёх глав ведут к соответствующим разделам полного прайса на `services.html`. «Гараж услуг» берёт цены из того же JSON (через `js/data.js`): программы мойки взаимоисключающие, их цена — для выбранного кузова.

Онлайн-запись у площадок разная: Мясницкая — компания 906067 в `n975571.yclients.com`, Технопарк — компания 1743348 в `n1982508.yclients.com`. Общий адрес открывал только Мясницкую, поэтому окно записи и карточки локаций ведут в запись своей площадки. Адреса лежат в `meatwash-content.json` рядом с данными локации; `npm run check` следит, что обе ссылки есть на странице.

Неподтверждённые «1000+ клиентов» удалены. Рейтинг 5.0 указан в исходном сайте; 28 сентября 2026 виджет Яндекс Карт показывал 5,0 у обеих студий. Блок клуба рассказывает о реальных сертификатах и корпоративном уходе, без выдуманного платного членства. Никакие заявки не имитируются и не отправляются локальным сервером. Yclients — внешняя система; автоматический выбор услуги и филиала через недокументированные параметры не используется (форма понимает `?o=s<ID>`, но цены программ на Мясницкой в yclients расходятся с сайтом — решает владелец).

## Яндекс Карты

«На карте» в карточках локаций и в подвале открывает окно с данными студии и виджетом карточки организации Яндекс Карт (`map-widget/v1/org/<slug>/<id>/?ll=<lon,lat>&z=16`, формат кода «Поделиться → Встроить»). Виджет создаётся только при открытии и только для выбранной студии; вкладки переключают студию. Пока скрипт окна не загрузился — или если он не загрузился вовсе — «На карте» открывает карточку в Яндекс Картах. Org id и координаты — в `meatwash-content.json` (координаты взяты из данных самого виджета). «Построить маршрут» — `yandex.ru/maps/?rtext=~<lat>,<lon>&rtt=auto`.

## Проверка исходников

`npm run check` проверяет исходники и ресурсы, `npm run catalog` пересобирает каталог. Ручная проверка — в браузере: desktop/mobile, меню, цены, диалоги записи, «Гараж услуг», `?motion=reduce`, ошибки консоли и переполнение. См. `QA.md`.

Запросы к imagegen (улучшенный кадр клуба, первый кадр прошлой версии) — в `IMAGE-PROMPT.md`.
