2. Какие данные обрабатываются

2.1. Данные сервиса Яндекс Метрика — только с согласия посетителя. Если посетитель нажал «Принять» в уведомлении о cookie, Сайт подключает сервис Яндекс Метрика (ООО «ЯНДЕКС»), который обрабатывает: идентификаторы cookie, IP-адрес, сведения о браузере, операционной системе и устройстве, адреса посещённых страниц и источник перехода, дату и время посещения, действия на страницах (например, нажатие кнопок записи, открытие карты, гаража услуг), а также запись действий на страницах инструментом Вебвизор: перемещения и нажатия мыши, касания, прокрутка. Полей для ввода текста на Сайте нет, поэтому Вебвизор не записывает вводимые данные. Без согласия Яндекс Метрика не загружается и эти данные не собираются.

2.2. Настройки в браузере посетителя. Сайт хранит в браузере (localStorage и sessionStorage) выбранный тип кузова, выбор работ в гараже услуг, решение посетителя об использовании cookie и черновик заявки (до закрытия вкладки, без фотографий). Эти сведения остаются на устройстве посетителя и Оператору не передаются, пока заявка не отправлена.

2.3. Заявка с фото. Для работ, кроме мойки, на Сайте есть форма заявки: имя, номер телефона или иной контакт, сведения об автомобиле, выбранные работы и студия, комментарий и фотографии. Заявка отправляется только с согласия посетителя — без отметки о согласии форма не отправляется. Текст согласия — на странице «Согласие на обработку персональных данных при отправке заявки».

2.3.1. Онлайн-запись на мойку выполняется на стороннем сервисе YCLIENTS, на который ведут ссылки «Записаться»; обработку данных при записи регулируют правила этого сервиса.

2.4. Звонки. При звонке по номеру, указанному на Сайте, Оператору становится известен номер телефона звонящего. Он используется только для ответа на обращение.

2.5. Яндекс Карты. При открытии окна карты на Сайте загружается виджет Яндекс Карт (ООО «ЯНДЕКС»). Сервис может обрабатывать данные посетителя по своим правилам; до открытия окна виджет не загружается.

3.3. Ответ на обращение посетителя — для данных, указанных в п. 2.4.

3.4. Рассмотрение заявки: оценка объёма и стоимости работ, связь с посетителем для ответа и согласования визита — для данных, указанных в п. 2.3.
